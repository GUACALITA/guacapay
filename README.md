# guacapay

Send money to an email address. Card payments are collected with Rapyd; the transfer to the recipient runs over Open Payments on the Interledger testnet.

**Status:** project setup in progress. Nothing is runnable yet.

## Where to look

- `docs/CONVENTIONS.md`: naming, language, and code rules.
- `docs/`: architecture and decisions, added as the project grows.
- `prompts/`: the prompts used to generate the work, one file per topic.
- `REFERENCE_ANALYSIS.md`: background analysis used to plan the project.
- `AI_USAGE.md`: which AI tools were used, where, and how.
