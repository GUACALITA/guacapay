## 3. Components and configuration

No AI configuration files were added to this repository: no rules files, skills, plugins or custom settings. Claude Code ran with its default settings and the Claude Haiku 5.5 model.

Two outside tools were used during the work, and only for reading documentation: web search and web fetch. They were used to read the official Rapyd, Open Payments and Interledger documentation before writing the code that depends on it. The usage log above names the prompt where each lookup was made.

## 4. Human review

Every prompt was run one at a time, and the author of the project approved each step before the next one started. Each AI-generated change was checked in three ways:

1. **Automated tests** written for that step. The backend suite grew from 4 tests (prompt 02) to 117 and the gateway suite to 29, both run with networking disabled.
2. **Running services** where possible: the containers were built and checked with real HTTP calls. Where a check could not run, the prompt file says so.
3. **The prompt's own "Done when" list**, recorded in each prompt file with its result.

Some checks are still open, and they are listed in the prompt files and in `docs/SECURITY_REVIEW.md`: a real Rapyd webhook, email in a real inbox, and the Open Payments transfer. The security review (prompt 15) found and fixed one high-severity dependency issue. Nothing here has had an independent human review yet, so the team should review the code before any real money flows through it.
