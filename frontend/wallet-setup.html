Wallets

Set up a test wallet

guacapay does not create wallets or accounts for you. The email check and the identity steps are done by you, on the official site. Nothing on this page asks for a password, a recovery phrase, a code from your wallet or a private key.

Create the wallet

  1. Open the official sign-up page.

    Open the Interledger Test Wallet sign-up page

    The sign-up link is not available. Try again later.

  2. Verify your email and complete the identity steps. Only you can do this, with your own email.

  3. Create a wallet account, deposit play money, and add a wallet address. Copy the wallet address. It starts with https://.

  4. Come back to guacapay and link the address.

    Go to the wallet linking page

Register a key in your wallet

These steps are from the Open Payments documentation. The official page is linked below.

  1. In the test wallet, open Settings, then Developer Keys.
  2. Expand your wallet account, then generate a key pair.
  3. A private.key file downloads. Keep it on your own computer. Do not upload it, and do not paste its contents anywhere. guacapay never asks for it.
  4. The key ID appears on the screen. Note it; it is not a secret.

Not covered by the documentation

The documentation does not say the following, so this page does not describe them:

  • how the key ID is formed;
  • what the wallet shows after the key pair is generated, beyond the key ID;
  • how a key from guacapay is registered in your wallet. guacapay does not register keys in your wallet.
